# zandy 0.0 Release Notes

## Overview

The 0.0 versions were released as zandy, installed with Homebrew, before confine was built around Nix. For the current version, see [confine 0.1.0](0.1.0.md).

## 0.0.8, 2026-09-25

### New Features

- Named presets: one launcher for any CLI coding agent. A preset is required.

## 0.0.7, 2026-06-23

### New Features

- Built with Zig 0.16.

## 0.0.6, 2026-06-17

### New Features

- zandy builds the Seatbelt profile itself and applies it in-process instead of running `sandbox-exec`. Everything is denied by default.

## 0.0.5, 2026-04-10

### New Features

- A first profile for Claude Code.
- The network-only profile is reworked.

## 0.0.4, 2026-03-30

### New Features

- A second profile: network only.

## 0.0.3, 2026-03-17

### New Features

- Installed with Homebrew.

### Resolved Issues

- Fixed: a rename could leak a file out of the sandbox. Processes are hardened.

## 0.0.2, 2026-03-15

### New Features

- The config is inlined into the binary.

## 0.0.1, 2026-03-10

### New Features

- zandy runs opencode under `sandbox-exec` with a hand-written profile, so it can't read files like `.env`, `~/.ssh` or `~/.aws`.
