# confine 0.1.0 Release Notes

Released 2026-11-23.

## New Features

- The broker runs your tools, like `glab` and `aws`, outside the sandbox with your login.
- Gateways let the program reach an API without seeing its key.
- `--confine-secret` stores a secret in confine's keychain.
- An env is configured in `confine.toml`, with a schema for editors.
- `confine-<name>` runs the command you name, or a shell.
- `--confine-config` prints the env's config and Seatbelt profile.
- Sessions, denials and proxy tunnels go to the unified log, subsystem `tbsklg.confine`.
- A forward proxy logs each tunnel's host, port, bytes and duration.
- Dot paths in the project are read-only.

## Known Issues

- `anthropicOauth` reads the token once; restart if a session outlives it.
- A symlinked git config, e.g. from home-manager, might not be readable.
- `#!/usr/bin/env` scripts might not run.
- npm needs `--cache "$TMPDIR/npm"`.

## Deprecations

- zandy is now confine: rename `~/.zandy`, the keychain, `zandy.toml` and the flake inputs.
- Envs live in `~/.confine/envs/<name>/`.
- Presets, gateways and adapters moved to confine-ports; configure them in `confine.toml`, not `flake.nix`.
- Name the command: `confine-dev claude`, not `confine-dev`.
- Presets no longer have `binary` or `args`.
