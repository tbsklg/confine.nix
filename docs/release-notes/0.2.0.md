# confine 0.2.0 Release Notes

Unreleased.

## Overview

confine 0.2.0 runs on macOS on Apple Silicon and needs [Nix](https://nixos.org/download) with flakes.

## Installer

### New Features

- `confine init [name]` creates `~/.confine/envs/<name>` from the template, builds its schema and installs `confine-<name>`. The name defaults to `dev`. Install confine with `nix profile install github:tbsklg/confine.nix`, then run `confine init`.
- `confine init` refuses an env that exists, and removes what it created when a step fails, so it can always be run again.
- If Nix isn't installed, `confine init` says so and links to the Nix download.
