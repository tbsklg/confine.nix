# Release notes

What changed in each version of confine: new features, resolved issues, known issues and deprecations. What you have to change after an update is under Deprecations. Why confine works the way it does is in the [architecture decisions](../adr/README.md).

## Bug reporting

Open an issue at [github.com/tbsklg/confine.nix/issues](https://github.com/tbsklg/confine.nix/issues). Include the version from the banner `confine-<name>` prints, e.g. `confine 0.1.0`, and the [debug log](../logging.md).
